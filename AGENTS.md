# AGENTS.md — loadouts

Source of truth for agents working in this repo. This is my
[loadout](https://github.com/josemiguelo/loadout) config repo — what each
machine should have installed, how to install it, and (in `state/`, generated,
never hand-edited) what it actually has. See `README.md` for the user-facing
tour of layout and commands.

## Working agreement

**Never run `git commit` or `git push` in this repo unless I've explicitly
told you to, in that message.** Prepare changes, stage them, show me the
diff — that's fine. Don't commit or push on your own judgment, even if a
task seems to call for it (adding a program, syncing state, anything). If
I haven't said "commit" or "push", wait for me to say so.
